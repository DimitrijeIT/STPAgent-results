# STPAgent — Companion Artifacts

Reproducibility package for:

> **STPAgent: A Writer-Reviewer Multi-Agent Architecture for AI-Assisted Unsafe Control Action Identification**
> Stojanović, Pavković, Četić.
> *Journal of Systems Architecture* (under review).

This repository contains the data, prompts, and analysis scripts behind the
ParkingPilot case study reported in the paper: **231 Unsafe Control Actions
generated by a Writer–Reviewer multi-agent system, evaluated by six
ISO 26262-certified safety engineers.**

## Repository layout

```
├── data/
│   ├── parkpilot_full.json              # Original end-to-end STPA dump (steps 1-4)
│   ├── parkingpilot_spec/               # System specification, split per artifact type
│   │   ├── losses.json                  # 8 losses
│   │   ├── hazards.json                 # 20 hazards
│   │   ├── system_constraints.json      # 23 system-level constraints
│   │   ├── controllers.json             # 9 controllers + 31 control actions
│   │   └── control_structure.json       # Topology used in Step 2
│   └── ucas/
│       ├── ucas.json                    # 231 UCAs (flat list, all fields)
│       └── ucas.csv                     # Same data in CSV form
├── evaluation/
│   ├── STPAgent Evaluation.xlsx        # Aggregate counts per evaluator (A--F)
